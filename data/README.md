# Excel求人の更新と写真の追加

Supabaseは使用せず、`imported-jobs.json` をNext.jsサーバーで読み込みます。
初回取込は「サンプル.xlsx」の6,386求人、全57列。既存16求人と合わせて6,402件です。
全件の詳細データはブラウザーに配信せず、検索結果の概要だけ20件ずつ返します。

## Excelを更新する

プロジェクトのルートで実行します（Python 3の標準ライブラリのみ使用）。

```sh
python3 scripts/import-jobs.py '/path/to/更新した求人.xlsx'
node node_modules/next/dist/bin/next build
```

先頭シートの1行目を見出し、求人IDを識別子として取り込みます。
同じ列構成のExcelを使ってください。原文、改行、空欄を保持します。
IDが重複・不正な場合は保存前に停止します。
Excel由来の求人全体を入れ替えるため、新しいExcelにない求人は一覧から消えます。
既存16件は別管理のため残ります。更新後はNext.jsサーバーを再デプロイしてください。

- Excelに企業名の列がないため、一覧の上段は勤務地を表示します。
- 追加求人の本文・項目名は日本語原文です。他言語画面には日本語掲載の案内を表示します。
- 詳細ページでは値がある全項目を表示し、空欄の項目は省略します。
- 元データはそのまま保存しています。原文の誤字や不整合の修正はExcelで行ってください。

## 写真を追加する

`public/images/jobs/求人ID.jpg` の形式で1求人1枚を置き、再ビルド・再デプロイします。
例：`public/images/jobs/112057.jpg`。
対応形式は `.webp` → `.jpg` → `.jpeg` → `.png` の優先順です。
写真がない追加求人は写真欄を表示しません。既存16件の写真は従来のままです。

## 動作確認

Next.jsサーバーを起動してから実行します。

```sh
node scripts/check-jobs.mjs http://127.0.0.1:3000
```

検索はサーバーで実行し、追加求人の詳細ページはアクセス時に生成・キャッシュします。
運用には `next start` 等のNode.js実行環境が必要です。静的HTMLのみのホスティングは対象外です。
