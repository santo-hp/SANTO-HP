# Excel求人の更新と写真の追加

Supabaseは使用せず、`imported-jobs.json` をNext.jsサーバーで読み込みます。
初回取込は「サンプル.xlsx」の6,386求人、全57列。既存16求人と合わせて6,402件です。
全件の詳細データはブラウザーに配信せず、検索結果の概要だけ20件ずつ返します。

## Excelを更新する

プロジェクトのルートで実行します（Python 3の標準ライブラリのみ使用）。

```sh
python3 scripts/import-jobs.py '/path/to/更新した求人.xlsx'
node scripts/audit-job-images.mjs
node node_modules/next/dist/bin/next build
```

先頭シートの1行目を見出し、求人IDを識別子として取り込みます。
同じ列構成のExcelを使ってください。原文、改行、空欄を保持します。
IDが重複・不正な場合は保存前に停止します。
Excel由来の求人全体を入れ替えるため、新しいExcelにない求人は一覧から消えます。
既存16件は別管理のため残ります。更新後はNext.jsサーバーを再デプロイしてください。

- Excelに企業名の列がないため、一覧の上段は勤務地を表示します。
- 追加求人の本文・項目名は日本語原文です。他言語画面には日本語掲載の案内を表示します。
- 詳細ページでは値がある全項目を表示し、空欄の項目は省略します。
- 元データはそのまま保存しています。原文の誤字や不整合の修正はExcelで行ってください。

## 写真を追加する

`public/images/jobs/求人ID.jpg` の形式で1求人1枚を置き、再ビルド・再デプロイします。
例：`public/images/jobs/112057.jpg`。
対応形式は `.webp` → `.jpg` → `.jpeg` → `.png` の優先順です。
求人別の写真がない場合は、職種と仕事内容を確認したイメージ画像を使用します。
一覧・お気に入り・詳細ページで共通の対応を使用します。

### 職種とイメージ画像の対応

- `src/lib/job-images.ts`：参考画像32種類と既存の板ガラス写真、明確な職種の対応。
- `src/data/job-image-reviews.json`：複数の作業を含む職種、元の職種分類と仕事内容が異なる求人等の個別確認結果。求人IDごとに画像キー・理由・確認時点の内容のSHA-256を保存。
- 医療・介護・運転・塗装等にも追加の参考画像を使用します。製造工程が特定できない製造職は、工場作業の共通イメージを使用します。
- 製造・物流・設備・建築等は実作業を確認します。商材、歓迎資格、研修、会社紹介に出てくる単語から写真を決めません。
- 個別確認した職種・職種名・概要・本文が更新された場合や、未確認の職種が追加された場合は画像を保留し、監査で再確認対象として検出します。

2026-10-03時点で全6,402件・93種類の職種データを確認し、2,968件の個別対応を記録しています。
追加画像13枚を使用し、画像あり6,402件、写真なし0件です。
前回写真のなかった465件に画像を設定し、調理専任48件も厨房の画像に更新しました。
最終再確認では、元の職種分類と実際の仕事内容のずれ、追加写真への切替漏れ等を116件修正しました。
営業分類の人事・総務、事務分類のWeb制作・IT運用、来客受付、訪問診療支援等も仕事内容を優先しています。
共通の職種参考画像であり、作業対象・設備・勤務地など細部までの一致を示すものではありません。
同じ内容の求人もIDごとに記録し、更新時に個別に差分を検出します。

```sh
node scripts/audit-job-images.mjs
# 起動中のサーバーで、全求人の一覧画像と代表的な詳細ページも検証
node scripts/audit-job-images.mjs --server http://127.0.0.1:3000
```

監査は全件に画像があること、対応、参照ファイル、確認時点の内容、過去の誤判定例を検証します。
`reports/job-image-audit.html` に画像付きの検索可能な確認表、
`reports/job-image-audit.csv` に全求人ID・職種・採用画像・選定理由を出力します。
求人別の実写真を追加した場合は、カテゴリー画像とは別に目視確認が必要です。

## 動作確認

Next.jsサーバーを起動してから実行します。

```sh
node scripts/check-jobs.mjs http://127.0.0.1:3000
```

検索はサーバーで実行し、追加求人の詳細ページはアクセス時に生成・キャッシュします。
運用には `next start` 等のNode.js実行環境が必要です。静的HTMLのみのホスティングは対象外です。
